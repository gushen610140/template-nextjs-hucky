---
title: Theme configuration
description: Adjust base color, primary color, radius, and shadows from a popover
---

The home and dashboard top bars expose a theme configuration button (palette icon) next to the light/dark toggle. It updates the shadcn token set immediately.

## Options

| Option | Values |
| --- | --- |
| Base color | Neutral, Stone, Zinc, Mauve, Olive, Mist, Taupe |
| Primary color | Emerald, Blue, Violet, Rose, Orange, Red, Yellow, Teal; the second row adds macaron tones: Blush, Peach, Butter, Mint, Sage, Sky, Lilac, Periwinkle |
| Radius | None, Small, Medium, Large, Default, XL |
| Shadow | None, Soft, Default, Strong |

Settings are stored in `localStorage` under:

```text
hucky-theme-customization
```

They are restored after a reload. The Reset button returns to Neutral + Emerald + Default radius + Default shadow.

## Implementation

| Path | Purpose |
| --- | --- |
| `lib/theme-presets.ts` | Palettes, radius/shadow presets, token generation |
| `providers/theme-customizer-provider.tsx` | Load/save settings and write CSS variables to `<html>` |
| `components/theme-customizer.tsx` | Popover UI |
| `components/ui/popover.tsx` | Shared popover primitive |
| `components/ui/toggle-group.tsx` | Toggle groups for palette, radius, and shadow options |
| `app/[locale]/globals.css` | Bridge between shadcn tokens and Fumadocs |

The provider selects the light or dark palette from `resolvedTheme`, then applies the generated variables to `document.documentElement.style`.

## shadcn tokens

The customizer updates:

```text
--background / --foreground
--card / --card-foreground
--popover / --popover-foreground
--primary / --primary-foreground
--secondary / --secondary-foreground
--muted / --muted-foreground
--accent / --accent-foreground
--destructive
--border / --input / --ring
--chart-1 ... --chart-5
--sidebar / --sidebar-*
```

Radius is controlled by `--radius`; the existing `--radius-sm` through `--radius-4xl` tokens derive from it.

Light and dark share one base scale, so no separate configuration is needed. Light mode uses base-100 for the canvas, base-200 for neutral surfaces, base-300 for borders, and keeps cards and popovers white; dark mode uses base-950/900/800. Switching the base color therefore changes the light canvas visibly, not only the borders and text.

`components/ui` uses shadcn's classic default style, `radix-vega`. Components derive their corners from semantic tokens such as `--radius-*` instead of hardcoding `rounded-none` in every file, as the `sera` style did. Only structural cases, such as the line variant of Tabs and ToggleGroup with `spacing=0`, are intentionally square. Changing the variables above updates Button, Card, Popover, DropdownMenu, Tooltip, Sidebar, and the rest together. Keep the `style` in `components.json` unchanged when adding new components with the CLI.

Shadows use one indirection layer:

```text
--app-shadow-*  →  --shadow-*  →  Tailwind shadow utilities
```

That means `shadow-sm`, `shadow-md`, `shadow-xl`, and similar utilities follow the selected shadow preset.

## Fumadocs

Fumadocs reads its own `--color-fd-*` variables. The project imports the official bridge in `app/[locale]/globals.css`:

```css
@import "fumadocs-ui/css/shadcn.css";
```

It maps `--color-fd-*` onto shadcn tokens:

```text
--color-fd-background  →  --background
--color-fd-foreground  →  --foreground
--color-fd-primary     →  --primary
--color-fd-border      →  --border
--color-fd-ring        →  --ring
#nd-sidebar            →  --sidebar / --sidebar-*
```

The provider therefore only writes shadcn variables, and the docs sidebar, buttons, borders, and accents follow automatically. Docs `<Callout>` is also wrapped around shadcn `Alert`.

## Adding presets

In `lib/theme-presets.ts`:

1. Add a 50–950 scale to `BASE_SCALES` or `PRIMARY_SCALES`.
2. Add its label under `ThemeCustomizer` in `messages/zh.json` and `messages/en.json`.
3. The provider and popover discover it automatically.

For a new radius or shadow preset, update `RADIUS_PRESETS` / `SHADOW_PRESETS` and the matching translations.
