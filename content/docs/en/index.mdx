This is the documentation for **Hucky Next.js Template**.

It pre-builds the parts every full-stack app needs — auth, i18n, database access, UI primitives, and tooling — so you can start with product code instead of configuration.

## Tech stack

| Area | Choice |
| --- | --- |
| Framework | Next.js 16 (App Router, React Compiler) |
| UI | React 19, Tailwind CSS 4, shadcn/ui, Radix UI |
| i18n | next-intl |
| Auth | Logto + local sessions + RBAC |
| Database | PostgreSQL + Prisma 7 (driver adapter) |
| File storage | RustFS (S3-compatible) with presigned direct uploads |
| Package manager | Bun |
| Linting | Biome |

## Project layout

```text
app/
  [locale]/           # all pages, grouped by locale
  api/                # route handlers
components/           # UI components
content/docs/         # Markdown for this site
i18n/                 # next-intl routing and request config
lib/                  # utilities, Prisma client, session
providers/            # global providers
prisma/               # schema and migrations
proxy.ts              # auth + i18n middleware
```
