[OpenCode](https://opencode.ai/) is the recommended AI agent for this project. It understands project-level skills natively, discovers `.agents/skills/` automatically, and works with the `skills` CLI to restore skill packs.

## Suggested workflow

- Start `opencode` from the repository root so the session inherits the project context.
- Use worktrees to isolate feature branches and keep parallel tasks from polluting each other's working tree.
- Use the `auto-continue` plugin to keep validating, testing, and fixing after the agent thinks the task is done.
- Put repeatable workflows in a skill instead of repeating them in every prompt.
