这是 **Hucky Next.js Template** 的使用文档。

它把全栈项目里重复度最高的部分先搭好：认证、国际化、数据库、UI 基础组件和工程化配置，让你从业务代码开始，而不是从配置开始。

## 技术栈

| 领域 | 选型 |
| --- | --- |
| 框架 | Next.js 16（App Router、React Compiler） |
| UI | React 19、Tailwind CSS 4、shadcn/ui、Radix UI |
| 国际化 | next-intl |
| 认证 | Logto + 本地 Session + RBAC |
| 数据库 | PostgreSQL + Prisma 7（driver adapter） |
| 文件存储 | RustFS（S3 兼容对象存储）+ 预签名直传 |
| 包管理 | Bun |
| 代码规范 | Biome |

## 目录速览

```text
app/
  [locale]/           # 所有页面，按语言分组
  api/                # Route Handlers
components/           # UI 组件
content/docs/         # 本文件的 Markdown 内容
i18n/                 # next-intl 路由与请求配置
lib/                  # 工具函数、Prisma client、session
providers/            # 全局 Provider
prisma/               # schema 与迁移
proxy.ts              # 鉴权 + 国际化中间件
```
