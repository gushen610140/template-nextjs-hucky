## 权限与入口

| 角色 | 权限 | 能看到 |
| --- | --- | --- |
| 普通用户 | `file:own` | 侧边栏「文件 → 我的文件」 |
| 管理员 | `file:manage` | 「我的文件」与「全部文件」 |

新注册用户会自动获得 `user` 角色；如果某个账号看不到文件入口，请让管理员在 `/dashboard/users` 里分配角色，或在权限页确认 `file:own` 已挂到对应角色上。

## 上传文件

- 点击右上角「上传文件」，可以一次选择多个文件。
- 把文件从资源管理器拖到页面任意空白处，会出现上传遮罩，松手即开始上传。
- 拖到某个**文件夹行**上松手，文件会直接上传进该文件夹。
- 上传过程中每一行都有独立进度条；单个文件最大 200 MB。

上传是浏览器直传对象存储，进度条反映的是浏览器到 RustFS 的真实传输。上传完成后应用会回查对象大小，校验失败会提示「上传未完成，请重新上传」。

## 文件夹

文件夹是虚拟分组，不会在对象存储里创建目录，也不会移动或复制对象。

| 操作 | 方式 |
| --- | --- |
| 新建 | 右上角「新建文件夹」，或在空白处右键 →「新建文件夹」 |
| 进入 | 双击文件夹行 |
| 返回 | 面包屑点击任意层级，或点「返回上一级」 |
| 移动文件 | 拖拽文件行到目标文件夹行，或拖到面包屑的任一层级 |
| 重命名 | 行尾铅笔按钮，或右键 →「重命名文件夹」 |
| 删除 | 行尾删除按钮，或右键 →「删除文件夹」 |

删除文件夹的行为与删除文件不同：

- 文件夹本身被**永久删除**。
- 文件夹及其子文件夹中的所有文件被**软删除**（记录保留，对象尽力清理）。
- 同层级不能存在同名文件夹，重名会提示「当前目录下已有同名文件夹」。

## 搜索、排序与分页

- 搜索框匹配**文件名和文件夹名**。在某个目录内输入关键词时，会在当前用户的整个目录树中查找，不局限于当前层级。
- 点击表头的「名称」「大小」「上传时间」切换排序，再次点击切换升序/降序。文件夹始终排在文件上方，按名称升序。
- 列表默认每页 10 条，翻页会保留搜索词、排序、当前目录和每页条数。

## 预览文件

- 单击文件行，或点击行尾的眼睛按钮，进入预览页；右键菜单里也有「预览」。
- 返回按钮优先回到浏览器上一页，列表的搜索、排序、目录状态都会保留。
- 预览页的「编辑」只对文本类文件开放，详见[文件预览](/zh/docs/file-preview)。

## 右键菜单

| 位置 | 菜单项 |
| --- | --- |
| 文件行 | 预览、重命名、下载、删除 |
| 文件夹行 | 重命名文件夹、删除文件夹 |
| 空白区域 | 新建文件夹 |

在输入框、按钮和面包屑上右键会保留浏览器默认行为。

## 管理员视图

「全部文件」默认平铺显示全站文件，只提供搜索、排序和分页。点击工具栏的「全部用户」按钮会打开用户列表对话框：

- 选择某个用户后，页面切换成该用户的目录视图，文件夹、上传、新建、拖拽移动、右键菜单全部可用。
- 此时的上传与新建都会写入所选用户，而不是管理员自己。
- 选择「全部用户」返回平铺视图。

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 上传失败，控制台报 CORS | bucket 未配置前端域名，或未允许 `PUT` |
| 上传失败，报 `SignatureDoesNotMatch` | `RUSTFS_ENDPOINT` 与浏览器访问的 host 不一致 |
| 下载 403 | 预签名已过期（15 分钟），重新点一次下载即可 |
| 看不到文件入口 | 当前角色没有 `file:own` |
| 文件已上传但列表里没有 | 服务端确认时存储不可达，记录停在 `PENDING`；点列表顶部的「重试确认」 |
| 拖拽无反应 | 只有文件行可拖拽，文件夹行只作为落点 |
